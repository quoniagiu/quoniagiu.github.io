关于 KARAS鸦

我们是谁，以及我们如何创作。

创作理念

KARAS鸦 成立于2020年，由一群热爱叙事与像素艺术的独立开发者组成。我们的核心信念是：游戏不仅是娱乐，更是表达情感与探讨哲学的媒介。我们拒绝随波逐流，坚持探索那些鲜为人知的题材与玩法机制。

技术栈

主要使用 Unity 引擎进行开发，辅以 C# 与 Shader Graph 实现视觉效果。美术风格融合了复古像素与现代光影渲染技术。
